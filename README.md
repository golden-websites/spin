# 🎉 چرخه شانس جشن ولادت

سایت تعاملی چرخه شانس برای جشن ولادت رسول اکرم و امام صادق (علیهم السلام)

## 🎯 ویژگی‌های اصلی

### 1. **رابط کاربری حرفه‌ای**
- طراحی مدرن و زیبا
- رنگ‌های جذاب و هماهنگ
- انیمیشن‌های نرم و جذاب
- کاملاً پاسخگو (Responsive) برای تمام دستگاه‌ها

### 2. **چرخه شانس**
- 12 بخش متنوع
- گرادینت‌های رنگی جذاب
- متون فارسی‌شده کامل
- انیمیشن‌های صاف و حرفه‌ای

### 3. **جوایز**
- 📱 Call of Duty Mobile (سطح 200, 300, 400)
- 💰 CP (100, 200, 500)
- 🎁 بخش‌های خالی

### 4. **ویژگی‌های خاص**
- اگر نام `آسنا` یا `Asena` یا `Asna` وارد شود:
  - پیام ویژه: "بیا یکم گوشیمو نگه دار"
  - انیمیشن‌های تخصصی و قلب‌های رقصان
  - اثرات جشن (Confetti)
- گردونه **همیشه روی جایزه خالی** می‌افتد
- صدای جذاب برای چرخش و پیروزی

### 5. **ویژگی‌های اضافی**
- نماد و ایموجی‌های جذاب
- اطلاعات و راهنمای کامل
- فرم تماس
- اعلام‌های خطای مناسب
- نوار کیبوردی (فشار Enter برای چرخش)

## 🛠️ فناوری‌های استفاده‌شده

- **HTML5**: ساختار معنایی
- **CSS3**: طراحی پیشرفته با انیمیشن‌ها
- **Canvas API**: رسم چرخه
- **Web Audio API**: اثرات صوتی
- **JavaScript ES6+**: منطق تعاملی

## 🚀 نحوه استفاده

1. فایل‌ها را باز کنید
2. `index.html` را در مرورگر باز کنید
3. نام خود را وارد کنید
4. دکمه "چرخه را بچرخان!" را کلیک کنید
5. نتیجه را بگیرید!
